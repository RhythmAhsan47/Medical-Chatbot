# Medical-Chatbot

# How to run?

### Steps:

Clone the repo

```bash 
git clone https://github.com/RhythmAhsan47/Medical-Chatbot.git
```

```bash
conda create -n medibot python=3.13 -y
```

```bash
conda activate medibot
```


```bash
pip install -r requirements.txt
```
